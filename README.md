# CHOGWARE 🐸💾

### A little piece of the internet, running on Windows 98 energy.

**CHOGWARE** is an interactive, Windows 98-inspired web environment built for the CHOG ecosystem. It boots up like an old-school PC, takes you through a login screen, and opens into a desktop filled with custom applications and community experiences.

🌐 **Live Demo:** [chogware.lol](https://chogware.lol)

## 🖥️ The Experience

CHOGWARE isn't just a retro-styled website. It's a playful desktop environment designed to make exploring the CHOG ecosystem feel like using a computer from another era.

- **BIOS & Boot Sequence** — A nostalgic startup experience.
- **Desktop Environment** — A Windows 98-inspired interface with interactive icons and windows.
- **CHOG Terminal** — Explore CHOG Finance features.
- **CHOGSpace** — Community messaging experience.
- **CHOGMii** — Create and customize PFPs.
- **CHOGPLAYER 2000** — A custom music-player experience.
- **Genesis.app** — Quick access to OpenSea.
- **gae-arts.app** — Explore community artwork.
- **614_LOST.exe** — A recovery-fund experience woven into the CHOG lore.
- **CHOGBRO.EXE** — A little dose of CHOG-flavoured chaos.

## 🎨 Design Philosophy

Inspired by the era of Windows 98, desktop icons, classic window chrome, pixel aesthetics, and the feeling of discovering something hidden on an old computer.

The goal is to bring that nostalgia into a modern, interactive experience for the CHOG community.
